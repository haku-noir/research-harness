# ハブに報告する

作業セッションで使います。手順は `<hub>/harness/roles/common.md` の「3. 報告」に従います。ハブの外で動く会話にはこのスキルが読み込まれないので、手順の本体はそちらに置いています。`<hub>` は指示書に書いてあるハブのパスです。

統括が持つファイル（`hub/state.md`、`hub/workstreams.md`、`hub/decisions.md`、`hub/glossary.md`、`hub/briefs/`）には書きません。変えてほしいことは、報告の「統括への提案」と「用語集に足すもの」に書きます。
