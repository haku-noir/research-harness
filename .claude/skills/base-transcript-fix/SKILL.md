# 文字起こしを修正する

目的は、要約ではなく、**発言を研究の用語で正しく読める形に直すこと**です。指導教員の言い回しや主張は変えません。

## 1. 受け取る

研究者に確かめます（分かっているものは聞かない）。

- 文字起こしの本文：貼られたテキスト、またはファイルのパス
- 日付（YYYY-MM-DD）
- 種類：指導教員との議論、ゼミの議事録、レビュー、コメントなど。名前は `hub/profile.md` の指導教員の呼び方に合わせる。
- 題：本文を読んでから案を出す。

`hub/profile.md` で生の文字起こしを残す設定なら、本文をそのまま `chats/raw/<日付>_<題>.txt` に保存します（git の外）。

## 2. 準備する

次のものを読みます。

- `hub/glossary.md` の全体：用語、固有名詞、誤認識の表、使わない語
- `hub/profile.md`：人の呼び方、秘密
- `hub/state.md`：いま何の話をしている時期か
- 話の続きに当たる `chats/` のファイル（題や日付から分かれば）

## 3. 直す

- **研究に関係する部分を残す。** 予定の確認や雑談は削り、何を削ったかを注記に書く。研究者が「全部残す」と言えば残す。
- **誤認識を直す。** 用語集の誤認識の表と用語の表を使う。表に無いものは文脈から判断し、注記の表に「原文の表記 → 修正後」を書く。
- **整文する。** フィラー、言い直し、重複を除く。語順や言い回しは、意味が変わらない範囲で整える。主張の強さ（「〜だと思う」「〜に決まっている」）は変えない。
- **話者を付ける。** 録音の話者の分離が無ければ、文脈から推定したと書く。
- **補った語は［ ］に入れる。** 復元できない箇所は［不明瞭］とする。確証の無い修正は、注記の「確証のない箇所」に、どう判断したかを書く。
- **話題で節を分ける。** 見出しは、その節で話していることを短く書く。
- **足さない。** 発言に無い内容、解釈、まとめを本文に入れない。

形は `harness/templates/transcript.md` に従います。

## 4. 置く

- ファイル名：`chats/<種類>：<題>（文字起こし修正）.md`
- 日付と、どの相談のものか（「相談の記録」の行）を、本文の冒頭に書く。相談ではないもの（一人で録ったメモ、指導教員から届いた文書など）は「なし」と書く。
- `chats/` に同じ題があれば、上書きせずに研究者に聞く。

## 5. 相談の記録につなぐ

`harness-meeting-record` の「3. 文字起こしをつなぐ」に渡す。相談の記録への書き込み、決定の候補の提示、論旨とのずれの提示は、そちらで行う。この見本を研究で置き換えても、この段は残す。

## 6. 用語集を更新する

`hub/glossary.md` に、次のものを 1 行ずつ足します。出典の列や文脈の列には、このファイル名を書きます。統括でない会話でこのスキルを使ったときは、用語集を直接書き換えず、報告の「用語集に足すもの」に書きます（`CLAUDE.md` のファイルの持ち主）。

- **誤認識の表**：今回直した誤認識のうち、また起きそうなもの
- **固有名詞**：新しく出た人名・文献・機材
- **用語**：指導教員が新しく使った用語。定義はまだ書かず、「定義は未決」と書く。定義を決めるのは論旨の作業。

足したものを研究者に一覧で見せます。

## ほかの場所で直すとき（ウェブの AI のプロジェクト機能など）

ハブの外で文字起こしを直すこともできます。

1. プロジェクトの知識に、次の二つを入れる。
   - `hub/glossary.md`
   - このファイル（`.claude/skills/base-transcript-fix/SKILL.md`）
2. 生の文字起こしを送って直させる。
3. 結果を `chats/` に置く。
4. ハブの会話で「用語集だけ更新して」と頼む。そのファイルの注記の表から、6 と 5 だけを行う。冒頭に「相談の記録」の行が無ければ足す。

用語集は手元で育つので、プロジェクトの知識の用語集も、ときどき差し替えてください。文字起こしの内容を外部のサービスに送ることになるので、`hub/profile.md` の秘密に照らして、送ってよいかを研究者が決めます。

## 守ること

- **外に送らない。** 文字起こしの内容を、ウェブ検索や外部のサービスに送らない（`hub/profile.md` の秘密）。
- **すぐに論旨を変えない。** 修正の後、論旨の正本をすぐに変えない。指導教員の発言を論旨に入れるかは、ずれを示した後で研究者が決める。
