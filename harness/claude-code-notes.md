# Claude Code での補足（デスクトップ版・CLI）

ハーネスの約束（`CLAUDE.md`）とスキルの手順は、どの道具でも同じです。ここには、Claude Code のアプリ（デスクトップ版、CLI）によって違う操作をまとめます。

- Claude Code 以外の AI では当てはまりません。その AI に合わせた読み替えは、導入のときに作ります（`harness/other-ai.md`）。
- アプリの更新で変わることがあります。
- 「決まり」と書いたもの以外は、研究者が状況に応じて選ぶための説明です。

## 作業の会話を起動する

`harness-dispatch` の「5. 起動する」で使います。起動の文は、どの道具でも同じです。

> `<hub>/hub/briefs/<id>.md` を読んで、その指示に従って始めてください。

**デスクトップ版**：統括が、会話を起動する道具（`start_session`）で起動する。

- 作業の場所をディレクトリにする。
- 起動の文と、指示書の要約（3〜5 行）を渡す。レビューのときは要約を添えない（`harness/roles/review.md`）。
- 作業の場所がハブの外なら、作業の会話はハブ（報告、記録、要約）にも書く。書き込みのたびに許可を聞かれることがあるので、研究者に、ハブのフォルダを追加のディレクトリとして許可するよう伝える。
- 文脈は新しく始める。統括の会話を引き継がない。
- リモート操作で使っているときは、起動できないことがある。そのときは CLI と同じように、研究者に起動の文を示す。

**CLI**：統括は起動できないので、研究者に次を示す。研究者が新しい端末で実行する。

```
cd <作業の場所>
claude '<hub>/hub/briefs/<id>.md を読んで、その指示に従って始めてください。' --add-dir '<hub>'
```

起動の文は `--add-dir` より前に書く。`--add-dir` は複数のディレクトリを受け取るので、後ろに書いた起動の文もディレクトリとして読まれるため。

## 作業の会話が終わったことを知る

`harness-dispatch` の「6. 報告を受けたら」を始めるきっかけです。

- **デスクトップ版**：統括が起動した会話は、ターンが終わると統括に知らせが届く。ただし、デスクトップ版で一度も開いたことの無いフォルダで起動した会話などでは、届かないことがある。届かなければ、研究者が統括に「終わった」と伝える。
- **CLI**：知らせは無い。研究者が統括に「終わった」と伝える。

## 作業の会話は、統括の会話の子になる（デスクトップ版）

統括が `start_session` で作業の会話を起動すると、その会話は統括の会話の下に畳まれた子のセッションになります。

- **一つの会話**：開いて、研究者が直接話しかけ、止められます。会話の中で動くサブエージェントとは違います。
- **親への知らせ**：子のターンが終わると、親（統括）に知らせが届きます。親は同じ子に追加のメッセージを送れます。
- **メッセージの扱い**：会話どうしのメッセージは、Claude Code では「参考の情報」として扱われ、研究者の指示にはなりません。承認を伝えるときは、研究者の言葉を引用します（`CLAUDE.md` の「承認と決定」）。
- **親の下から外す**：子は、親の下から外して独立した会話にできます。研究者がアプリで行うか、Claude に頼みます。

CLI には、会話どうしの技術のつながり（子のセッション、知らせ、メッセージ）はありません。指示書と報告のファイルだけでつながります。

## 統括を新しい会話に替えるとき（デスクトップ版）

進行中の作業の会話は、前の統括の子のまま残ります。ターンの終わりの知らせも、前の統括に届き続けます。

- **ハーネスとしての決まり**：新しい統括は、始めるときに `hub/workstreams.md` の「セッション」の欄にある会話の状態を確かめる。研究者の答えを待っている会話や、終わった会話が無いかを見る。知らせが届かなくても見落とさないため。
- **研究者が選べること**：
  - 進行中の作業の会話を、前の統括の下から外す。
  - 前の統括の会話を、作業の会話が終わるまで残しておく。

## 会話を閉じる・アーカイブする

- デスクトップ版の会話は、閉じるまで残ります。
- 会話が終わるときのフック（会話の記録、記録どうしのリンク）は、会話を閉じたとき（CLI では終了したとき）に動きます。統括が報告を受けたときにも同じ処理を動かすので、閉じなくても記録は漏れません。
- 作業が終わった会話を閉じるか、アーカイブするかは研究者が決めます。Claude は聞くだけで、研究者に聞かずに閉じません。
