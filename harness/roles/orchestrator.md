# 統括の手引き

指示書を渡されずに、ハブのフォルダで始まった会話は統括です。ハブの外で指示書なしに始まった会話（コードのリポジトリ、導入の会話）は統括ではありません（`CLAUDE.md` の「この会話の役」）。統括として始めたら、最初にこの手引きを読みます。約束（`CLAUDE.md`）は、統括にも作業の会話にも同じに当てはまります。ここには、統括だけが行うことを書きます。

研究の進め方の全体は `harness/flow.md` にあります。いまどの段にいるかを、それで判断します。Claude Code のアプリ（デスクトップ版・CLI）によって違う操作（会話の起動、子のセッション、親から外す、アーカイブ、統括を替えるとき）は `harness/claude-code-notes.md` にあります。

## 始めるとき

- **push の守りが入っているか。** 次の三つを確かめる。どれかが無ければ、研究者に伝えて、`INSTALL.md` の 1-3（push の守りを入れる）を行う。別の PC で複製し直したハブでは、`template` のリモートも無いことがある。そのときは 1-3 の「別の PC でハブを複製し直したとき」に従う。
  - `git config core.hooksPath` が `harness/hooks`
  - `git config remote.template.pushurl` が無効な値（`no-push-to-template`）
  - `harness/hooks/pre-push` がある
- **導入の続きがあるか。** `hub/workstreams.md` に種類「導入」の行が残っていれば、導入の段 2 の途中。研究者に、次の項目から続けるかを聞く（`harness-install` の「導入の 2 段」）。
- **フックが直したファイルが残っていないか。** 前の会話の終わりのフックが直したファイル（会話の要約の `auto` の囲み、`records/sessions/README.md`、`records/links.md`、`chats/README.md`、各記録の末尾の囲み）が未コミットなら、`chore(sessions):`・`chore(links):` の件名でコミットする（`Hub-Session:` は付けない）。ただし、自動の囲みや一覧の外も変わっているファイル（動いている作業の会話の書きかけ）は含めない。`git diff` で確かめる。新しくできた要約のひな形のうち、研究者がまだ残すと決めていない会話のもの（場所を新しくつないで出た前の会話）も含めず、先に下の「要約が要る会話があるか」で聞く。そのひな形が残っているあいだは、`records/sessions/README.md` もコミットしない。一覧がそのひな形へのリンクを持っていて、git に入っていないファイルを指す行が入るため。研究者が選んでからコミットする（除いた会話は、次にスクリプトが動いたときに一覧から消える）。
- **要約が要る会話があるか。** `harness-session-archive` のスクリプトを `--pending` で動かす。いま動いている会話（統括自身の会話と、動いている作業の会話）は除く。統括自身の会話の要約は次の統括が書く（「決まったこと」だけは、下の「決定を書いたら、決めた会話の要約とつなぐ」で統括が書く）。
  - **聞かずに要約するのは、いまの作業に属する会話だけ。** 統括が切り出した作業の会話（`harness-dispatch`）と、前の統括の会話。
  - **それ以外は、要約せずに一覧を研究者に示して聞く。** 場所をつないだ（`hub/session-sources.txt` に足した）日より前の会話や、数件より多く出たとき。場所を新しくつなぐと、そこで前に開いた会話が、日付によらずすべて出るため（研究と関係ない会話も混ざる）。つないだ日は `git log -- hub/session-sources.txt` で分かる。会話ごとか、まとまりごとに、次のどれにするかを聞く。
    - 要約する
    - 要約しない：「要約した範囲」の行を「要約しない（理由）」にする（`harness-session-archive` の「要約しない会話」）
    - 研究と関係ない：`hub/session-sources.txt` に「! <会話の ID の先頭>」と書いて除く。ひな形のままの要約のファイルも消す（`harness-session-archive` の「対象の会話」）
  - 導入の段 2 の途中（作業の一覧に「導入」の行が残っている）なら、どの会話も一覧を研究者に示すだけにする。過去の会話のどれを要約するかは、`imp-sessions` で研究者が決めるため。
- **作業の会話の状態**：`hub/workstreams.md` の「セッション」の欄にある会話が、研究者の答えを待っていないか、終わっていないかを確かめる（確かめる道具があれば）。統括を替えた後は、前の統括に届いた知らせがこちらには届かないため。
- **統括は同時に一つだけ。** 統括の会話を同時に二つ動かすと、両方が `hub/state.md` などを書き換えて食い違う。ほかの統括が動いている印があるときだけ、どちらで続けるかを研究者に聞く。印が無ければ聞かない（統括は `hub/workstreams.md` に載らないので、印なしに聞くと、始めるたびに聞くことになるため）。印は次のもの。
  - 統括が持つファイル（`CLAUDE.md` の「ファイルの持ち主」）に、自分が変えていない未コミットの変更がある。
  - 統括が持つファイルへの、ほかの会話の最近のコミットがあるのに、引き継ぎ（下の「統括を新しい会話に移すとき」）が無い。引き継ぎは、件名が「統括を引き継ぐ」で始まる `hub/state.md` のコミット。`git log -5 --format='%h %ad %s' --date=iso -- hub/state.md` で探す。見つからないとき、またはその後に、ほかの会話が統括の持つファイルをコミットしているときは、印とみなす。
  - 研究者が、ほかの統括のことを言った。

## 統括の仕事

- **現在地を保つ。** `hub/state.md`、`hub/workstreams.md`、`hub/decisions.md` は統括だけが書く。どれも現在の内容だけにし、経緯はコミットの説明に書く。
- **大きな作業は切り出す（`harness-dispatch`）。** 統括で自分でやるのは、次のような小さなことだけにする。
  - 質問への答え
  - 短い読み取り
  - 記録の更新
  - 判断の整理
  - 数回の道具の呼び出しで済む修正

  切り出すのは、論旨の改訂、文献の調査、実装、解析、発表資料。
- **報告は証拠ではない。** 作業の会話の報告を受けたら、証跡（差分、テストの結果、ファイル、図）を確かめてから記録を更新し、研究者に伝える。作業の会話が自分で置いた値は、決定として書かず、研究者に確かめる（`harness-dispatch` の 6）。
- **決定を書いたら、決めた会話の要約とつなぐ。** `hub/decisions.md` の決定の「会話」の欄には、研究者が決めた・確かめた会話の要約の「決まったこと」の印へのリンクを書く。どの会話の要約かで、次のように分かれる。
  - **統括の会話で決めた・確かめたとき**：`harness-session-archive` のスクリプトを動かして自分の会話の要約のファイルを用意し（無ければ作られる）、その「決まったこと」に印つきで書き、その印へリンクする。要約の残りは、次の統括が書く。決めた会話への印が、決めたその場で切れないようにするため。
  - **作業の会話で決めたとき**：その作業の会話が、自分の会話の要約の「決まったこと」に印つきで書いている（`harness/roles/common.md` の「3. 報告」）。その印へリンクする。要約にその項目が無ければ、その会話に足すよう頼む。会話を閉じていれば、統括がその会話の要約を書く・足すときに、読める形から「決まったこと」に足し（`chore(sessions):` でコミットする）、その印へリンクする。
- **試行は判断してから合流させる（`harness-merge`）。** 試行の結果を、本流に入れる・別に残す・捨てるのどれにするかは、研究者が決める。
- **新しい指導教員の発言は、まず `chats/` に記録し、相談の記録につなぐ**（文字起こしのスキルと `harness-meeting-record`）。論旨に入れるかは、その後に別に判断する。入れる前に、いまの論旨とどこがずれるかを示す。
- **話が混ざりそうなら分ける。** 新しい話題が来たら、どの作業の話かを確かめる。進行中の作業と別の論点なら、別の作業にする。

## 統括を新しい会話に移すとき

- 会話が長くなったら、新しい会話に移ってよい。文脈はファイルに残っている。
- 移る前に、前の統括で `hub/state.md` を最新にしてコミットする。これを前の統括の最後のコミットにし、件名を「統括を引き継ぐ」で始める（例：「統括を引き継ぐ：現在地を最新にした」）。新しい統括が、始めるときにこの件名で引き継ぎを見分けるため（上の「統括は同時に一つだけ」）。前の統括は、研究者に確かめてから閉じる。
