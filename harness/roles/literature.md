# 文献の作業の手引き

先行研究を調べ、原文を保存して、論旨のどこに使えるかを整理する作業です。

## 保存の約束

- **原文と抜き書きは git に入れない。** 文献は他の人の著作なので、原文・抜き書き・長い引用をハブの git に入れない。
  - `literature/` で git に入るのは、参照の一覧 `literature/index.md` と `README.md` だけ（`.gitignore`）。
  - 論旨の正本や報告にも、原文の長い写しを貼らない。根拠は（著者 年）と箇所（ページ・節）で示す。
- **一覧に 1 行足す。** 文献を保存したら、`<hub>/literature/index.md` に 1 行足す。書くのは、文献を特定する情報だけ。
  - 書誌：著者、年、題、媒体
  - DOI・URL
  - 入手の状態
  - 手元の写しの場所
  - 話題

  要約や引用は書かない。
- **原文を保存する。** 保存先は `<hub>/literature/<話題>/sources/`。要約で済ませず、原文（PDF・本文のテキスト）を残す。
  - 引用に使う箇所は、原文から写した抜き書きとして残す（ページか節を付ける）。
  - 文献の調査に外部の道具を使っているなら、その道具の保存の形に従ってよい。ただし、この手引きの約束（原文を git に入れない、一覧に 1 行足す）は守る。
- **文献の場所を変えている場合は、プロフィールに従う。** `hub/profile.md` に文献の場所が別にあれば（例：`~/research/`）、そこに保存する。
- **取れない文献は、研究者に頼む。** 有料のもの、ボットの確認があるものは、回避しない。次の三つを示して研究者に頼む。
  - 開く URL
  - 保存先
  - ファイル名

  入手できなかったものは「有料・未入手」として記録する。
- **読んだかどうかを区別する。** 原典を読んだか、要旨だけか、他の論文の記述で見ただけかを区別して記録する。論旨の中でもこの区別が分かるようにする（印の付け方は `hub/rules.md`）。

## 秘密

- **検索語に入れない。** `hub/profile.md` の「秘密」にある内容（指導教員の未発表の考えなど）は、検索語に入れない。一般の語に言い換えて探す。

## 整理の仕方

- **論点と課題設定で整理する。** キーワードが同じだから使える、とは判断しない。各研究について、次を整理する。
  - 何を論点としていたか
  - その論点のために、どんな課題・条件・指標を置いたか
  - 結果は何か
- **使えることを、原文の箇所で示す。** 論旨のどの主張にどう使えるか、使えないなら何が違うかを、原文の箇所を示して書く。
- **先例が無いことは、範囲付きで書く。** 「先例が無い」は、調べた範囲（検索語、データベース、件数）と一緒に書く。
