# 会話を残す対象の作業ディレクトリ（harness-session-archive が読む）
# 1 行に 1 つ、絶対パスで書く。その下のフォルダとワークツリーで開いた会話も対象になる。
# ハブのフォルダは、書かなくても対象になる。
# 研究と関係ない会話を除くときは、「! <会話の ID の先頭>」と書く（後ろに説明を書いてよい）。
# 除いた会話の要約のファイルがひな形のままなら、統括が消す（harness-session-archive の「対象の会話」）。
# パスは引用符で囲んでもよい。ハブのフォルダを移したら、前のパスもここに足す。
# 「#」で始まる行だけが注釈になる。パスの行の途中の「#」は、パスの一部として読む（パスの後ろに説明を書かない）。
# 二つの PC で使うなら、PC ごとに「# <PC の名前>」の行の下に並べる。もう一方の PC の行は、この PC ではどの会話にも当たらないが、消さない。
# Claude Code で開く場所だけを書く。ほかの AI の会話は、スクリプトが読めないため（harness-dispatch の 4）。
#
# 例：
# C:\Users\name\my-experiment-code
# ! 0a1b2c3d
