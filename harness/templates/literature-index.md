# 文献の一覧

この研究で集めた文献の参照の一覧。

**ここに書くのは、文献を特定する情報だけ。** 原文、抜き書き、要約、引用は書かない。文献は他の人の著作なので、原文と抜き書きは git に入れない。

- 原文は、`hub/profile.md` の「文献」の場所（既定：`literature/<話題>/sources/`）に置く。どちらも git の外。
- `literature/` で git に入るのは、この一覧と `README.md` だけ（`.gitignore`）。
- 文献を保存したら、この表に 1 行足す。同じ文献が別の話題でも出たら、「話題」の列に足す。
- 論旨での使い方は、論旨の正本の「文献の使い方」に書く。

| 書誌（著者 年, 題, 媒体） | 種類 | DOI・URL | 入手 | 手元の写し（git の外） | 話題 |
|---|---|---|---|---|---|

- 種類：論文 / まとめ（総説・書籍） / 公式（規格・報告書・公式の資料） / 記事 / 動画 / データ
- 入手：原文 / 一部未読 / 要旨のみ / 未読 / 未入手（有料・ボット確認など）
